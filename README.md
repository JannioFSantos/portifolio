# Portfólio Flask

Projeto de portfólio pessoal desenvolvido com Python e Flask.

## Como executar

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

A aplicação ficará disponível em http://localhost:5000

## Personalização

Edite o arquivo `app.py` para alterar os projetos, links e dados do perfil.
Edite o arquivo `templates/index.html` para ajustar o layout e textos.
